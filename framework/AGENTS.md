# AGENTS.md

Pokémon-style gacha / merge / battle browser game with all UI text in Vietnamese.

**Policy: only develop in the Vue app (`framework/`). The legacy vanilla codebase is FROZEN — do not modify `vanilla/` anymore.** Treat `vanilla/` as read-only reference only (formulas, data, battle rules).

## The active codebase
- **Vue 3 migration** in `framework/` — Vite + Vue 3 `<script setup>` + Tailwind CSS v4.
- `framework/src/game/` holds the extracted pure logic as ES modules: `data.js`, `skills.js`, `stats.js`, `gacha.js`, `inventory.js`, `merge.js`, `shop.js`, `store.js`, `battle.js`, `campaign.js`, `gym.js`.
- `framework/src/game/store.js` exports a Vue `reactive` `store` singleton (same shape as legacy `vanilla/js/state.js`) with save/load. It reads/writes `localStorage` key `pokemonGameState`.
- UI is SFCs under `framework/src/components/` and `framework/src/views/`. Tailwind utility classes only — no custom CSS unless absolutely necessary.
- All 7 tabs render real views: Gacha (`views/GachaView.vue`, `components/gacha/*`), Roster (`views/RosterView.vue`, `components/poke/*` incl. Pokédex + detail modals), Merge (🧬 `views/MergeView.vue`, `components/merge/*`, logic in `game/merge.js` incl. talent unlock at V1/V3/V5), Shop (`views/ShopView.vue` — mua Kẹo Kinh Nghiệm), Inventory/Kho đồ (`views/InventoryView.vue`, `components/shop/*`, logic in `game/shop.js` incl. skill-select modal khi dùng Kẹo chạm mốc level chia hết cho 5), Campaign (⚔️ `views/CampaignView.vue`, logic in `game/campaign.js`) and Gym (🏟️ `views/GymView.vue`, logic in `game/gym.js`). Campaign + Gym share the reactive battle engine in `game/battle.js` and the battle UI in `components/battle/BattleArena.vue` (with `BattleTeamSelectModal.vue` for team setup).
- **World Map Navigation (Phaser 4)**: `src/components/map/WorldMap.vue` mounts a Phaser `Game` (v4.2.1, `phaser/dist/phaser.esm.js`) into a container and destroys it on unmount; the maps are rendered by `src/components/map/worldScene.js` (class `WorldScene`, one scene instance reused via `scene.restart({mapId, startPos})`, communicating to Vue through module-level `setWorldRuntime({callbacks, startPos})` + scene `init(data)`). Both maps are **Tiled JSON** registered in `src/game/maps.js`: `town` (`public/images/map/town/home_town.json`, 60×60 @16px, zoom 2 — **the only town file the game reads; always export the town map to this exact path**) and `house` (`public/images/map/main_house/main_house.json`, 64×96 @16px). **Tilesets are NOT listed in `maps.js` — `worldScene.resolveTilesets(json)` derives them from `json.tilesets` at load time** (2-phase preload: load the JSON, then resolve each `ts.image` → if it contains `/images/map/` use that substring URL-encoded, else join to the map JSON's folder), so adding/removing/renaming tilesets in Tiled needs zero code changes — just re-export + refresh. **Minimap location dots come from a `spots: [{id, name, type, x, y, icon}]` array on each map in `maps.js`** (`x`/`y` = tile center in world px, tile 16px); `type: 'location'` renders an amber dot, `type: 'quest'` renders a pulsing red dot (reserved for a future quest-navigation feature — just add a quest spot to make it show). `WorldMap.vue` falls back to legacy `LOCATIONS` (from `world.js`) only for `kind:'legacy'` maps. Town currently uses 2 tilesets: `tileset` firstgid 1 + `d9xkdox-…` firstgid 1301 (the new right-side building at cols 40–48). Convention: a tilelayer with `conclusion:1` = every tile ≠ 0 blocks movement. **Door (io) points are NOT stored as a tilelayer anymore — they are generated from the `doors` objectgroup** (each object rect with `to`/`toSpawn` expands to all covered tiles via `parseDoors` in `maps.js`; `worldScene.buildDoorPoints()` turns each `"col,row"` into an `io` interact point, so a door with no `doors` object in Tiled simply doesn't exist). Other interaction points (healing/quest/dialogue) still use a tilelayer whose property has `value >= 2` (e.g. hospital `npc` layer with `healing:3`), read by `buildInteractPoints()`. `io` points drive two-way door transitions (town door `31,19` → house at `main_door {40,24}`; house door `2,0` → town at `house_door {504,312}`; town `16,28`/`17,28` → hospital at `bv_door {120,200}`; town `44,28`/`45,28` → lab at `lab_door {120,40}`). Visual layers are created from every non-logic tilelayer (`view_1`/`view_2`); `view_2` is marked `visible:false` in Tiled but **must still be rendered** as the bottom filler (tile 262, opaque) because `view_1`'s roof tiles have transparent holes — the render loop ignores the `visible` flag. Legacy grid rendering (`src/game/worldmap.js` `getMapGrid`, `world.js` LOCATIONS/OBSTACLES) is now unused — only the legacy branch in `worldScene.js` (`buildTerrain`/`buildWalls`/`buildBuildings`) and `WorldMap.vue`'s minimap locations filter still reference it; keep it as reference. Movement: WASD/Arrows at `PLAYER_SPEED=160` world px/s, actual `moveSpeed = PLAYER_SPEED / zoom` so on-screen speed is consistent across maps; Arcade physics, player body `setSize(10,20)` offset `(3,12)`, world `setBounds(0,0,mapWidth,mapHeight)`. Interact radius = `tileSize` (16px); edge-triggered with debounce 30 + `lastInRangeLocId` anti-loop; `io` fires `onMapChange(to, toSpawn)` → `switchMap` in WorldMap.vue. Tiled maps get a black background and `setZoom(2)`; camera `startFollow(player, true, 0.12, 0.12)` when the map is larger than the viewport, else `centerOn` map center. Player sprite `player_red.png` = 9 frames of 16×32 (anims `walk-down/up/left`, right = `flipX`). `store.worldPos` persists position across sessions; `WorldMap.vue` also `watch(store.worldPos.mapId)` so external resets (GameHeader Reset → `resetGameState()`) restart the scene on the right map.

## Battle rules (verbatim from legacy)
- Turn order is normal turn-based — Tốc Độ (SPD) only decides who acts first when a Pokémon just enters the field (wave start / in-battle switch), tie = random 50/50; there is NO speed gauge / `spdGauge` / speed recovery — turns strictly alternate after the first move.
- campaign DoT = `%` of current HP, gym DoT = flat `val`; campaign enemies built with `baseHp + level*25` / `baseAtk + level*5` / `baseDef + level*3` / `baseSpeed + level*2`, gym enemies use exponential `Math.pow(1+rate, level-1)` growth.
- gym requires HLV level ≥ 25 to unlock, team must be same type and level ≤ trainer level, and completed gyms (progress ≥ 5) can't be rechallenged; gym buff +10% (`gymBuffs[type] = 0.1`) at 5 cleared, then `recalculatePokemonStats` for all that type.
- Status effects: `stun` (Choáng) makes the affected Pokémon lose 1 turn; `extra_turn` (Tăng Tốc +1 lượt) grants an extra attack on entry.
- DoT (`burn`/`shock`/`poison`/`bleed`) ticks at the **END of the afflicted Pokémon's own turn** (chuẩn Pokémon) — implemented via `processEndOfTurnDot`/`gymProcessEndOfTurnDot`/`towerProcessEndOfTurnDot` called after the acting side's `useSkill`/`executeBotTurn` (and on stunned-skip turns); start-of-turn processing only handles passives, stun, and buff/debuff duration ticks.
