# Sprite Pokémon (Official Artwork)

- **Nguồn:** PokeAPI Sprites — `https://raw.githubusercontent.com/PokeAPI/sprites/master/sprites/pokemon/other/official-artwork/{ID}.png`
- **Tên file:** khớp chính xác `name` trong `src/game/data.js` (vd `Pikachu.png`, `Ho-Oh.png`)
- **Cập nhật lại:** `powershell -ExecutionPolicy Bypass -File scripts/download-sprites.ps1`
- **Lưu ý:** ảnh thuộc bản quyền Nintendo/Game Freak/The Pokémon Company — chỉ dùng cho fan-project cá nhân.
