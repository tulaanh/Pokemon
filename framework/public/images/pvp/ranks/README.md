# Huy hiệu Rank PvP

Các SVG trong thư mục này là huy hiệu hình học tự tạo cho dự án, không sử dụng
tài sản Pokémon có bản quyền và không hotlink. Ý tưởng phân bậc Poké Ball tham
khảo hệ thống rank phổ biến của các game Pokémon; mã nguồn GitHub được kiểm tra
nhưng không tìm thấy bộ asset có giấy phép rõ ràng phù hợp để sao chép.
